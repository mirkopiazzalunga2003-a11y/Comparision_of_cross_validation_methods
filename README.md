
# Benchmark of Cross-Validation Techniques: Predictive Performance and Environmental Impact

## Repository Structure

The repository is organized as follows:

```text
repository/
│
├── data/
│   └── Input datasets
│
├── results/
│   └── Output files containing the benchmark results
│
└── src/
    ├── functions/
    │   ├── imports.py
    │   ├── metrics.py
    │   ├── my_cv_function.py
    │   └── Cross_validation_function.py
    │
    ├── main.py
    │
    └── pre_post_processing.py
```

### Main Components

- **`data/`**: Contains the input datasets used in the experiments.
- **`results/`**: Stores the results generated by the benchmark.
- **`functions/imports.py`**: Handles the required library imports and package setup.
- **`functions/metrics.py`**: Contains custom functions for calculating predictive performance metrics.
- **`functions/my_cv_function.py`**: Contains custom implementations of cross-validation procedures, written to illustrate the underlying algorithms and understand how the corresponding Scikit-learn methods work.
- **`functions/cross_validation_function.py`**: Contains the main function used to perform cross-validation and hyperparameter optimization according to the selected validation strategy.
- **`main.py`**: The main script. Run this file to execute the benchmark and generate results for the datasets loaded into the DataFrame.
- **`pre_post_processing.py`**: Contains descriptive statistics and procedures for data preprocessing and post-processing.

### Execution Workflow

To run the benchmark:

1. Place the input datasets in the `data/` directory.
2. Configure the dataset and load it into the DataFrame used by `main.py`.
3. Execute `main.py` to run the experiments.
4. The resulting predictive performance metrics, energy consumption, CO₂ emissions, and execution times are saved in the `results/` directory.

## Project Description

This repository hosts an experimental research project aimed at evaluating and comparing different validation strategies for Machine Learning models. The study examines both **predictive performance** (with a focus on clinical classification metrics) and **environmental impact** (energy consumption and CO₂ emissions) when training **Random Forest** models on 10 Electronic Health Record (EHR) datasets.

## Project Objectives

1. **Evaluation of Validation Strategies:** Compare classical and advanced sampling and resampling methods.
2. **Model Analysis:** Apply the **Random Forest** algorithm as the reference classifier across all datasets (the target variable is located in the last column).
3. **Comprehensive Predictive Metrics:** Assess the model's generalization performance in a clinical context.
4. **Green AI & Carbon Footprint:** Track the energy consumption and environmental footprint of each validation strategy using `CodeCarbon`.
5. **Special Study:** Conduct an empirical and theoretical comparison between **Out-of-Bag (OOB) Error** and **Nested Cross-Validation**.

## Validation Methods Compared

The methods implemented and analyzed in the benchmark are:

- **Traditional K-Fold Cross-Validation**
- **Repeated Hold-Out Validation**
- **Nested Cross-Validation** (for hyperparameter optimization and unbiased performance estimation)
- **Stratified K-Fold Cross-Validation** (particularly important for preserving class proportions in medical datasets)
- **Leave-One-Out Cross-Validation (LOOCV)**

## Evaluation Metrics

For each combination of *validation method* and *dataset*, the following metrics are calculated and saved.

### Predictive Performance Metrics

- **MCC** (Matthews Correlation Coefficient)
- **Sensitivity** (Recall / True Positive Rate)
- **Specificity** (True Negative Rate)
- **Precision** (Positive Predictive Value)
- **NPV** (Negative Predictive Value)
- **Accuracy**
- **F1 Score**
- **ROC AUC** (Area Under the ROC Curve)
- **PR AUC** (Area Under the Precision-Recall Curve)
- **Cohen's Kappa**

### Efficiency and Environmental Impact Metrics

- **Energy Consumption:** measured in watt-hours (Wh) using `CodeCarbon`.
- **CO₂ Emissions:** measured in grams of carbon dioxide equivalent (gCO₂eq) using `CodeCarbon`.
- **Execution Time:** measured externally in seconds (s).
